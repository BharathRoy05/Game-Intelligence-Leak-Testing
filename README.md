# Game Intelligence Leak Testing Project

## Project Overview

This project focuses on exploratory and manual testing of the GeoGuessr web application.

The objective was to evaluate whether answer-related information is exposed to end users through client-accessible resources and to assess the impact on gameplay integrity.

## Testing Types Performed

- Manual Testing
- Exploratory Testing
- Network Inspection Testing
- Gameplay Integrity Testing
- Negative Testing

## Tools Used

- Google Chrome
- Chrome DevTools
- Google Maps
- GitHub
- Microsoft Excel

## Key Finding

### High Severity Defect

Location coordinates were visible within a client-accessible network response.

A player could potentially use the exposed coordinates to identify the correct location externally and gain an unfair gameplay advantage.
